# MariaLog

Registro de entrenamientos para el móvil (PWA). Rutina de 4 días, horquilla 8–10 reps,
temporizador de descanso, récords, progreso por ejercicio, peso corporal y copia de seguridad.

## Publicar en GitHub Pages
1. Crea un repositorio (por ejemplo `marialog`) y sube estos archivos a la raíz.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. En 1–2 minutos estará en `https://TUUSUARIO.github.io/marialog/`.
4. En el iPhone, abre esa dirección en Safari → Compartir → Añadir a pantalla de inicio.

Los datos se guardan solo en el móvil (localStorage). Usa siempre el icono de la pantalla de inicio
y exporta una copia desde Perfil de vez en cuando.
